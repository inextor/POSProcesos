Fusionar Clientes

Atencion: esta accion no se puede deshacer. El cliente ORIGEN es el donante: todos sus datos se mueven al DESTINO y despues se marca como ELIMINADO. El cliente DESTINO es el receptor: conserva sus datos y recibe los del origen, incluyendo sus puntos. Se actualizan 18 tablas en una sola transaccion (ordenes, pagos, cotizaciones, devoluciones, movimientos bancarios, puntos, direcciones, cuentas bancarias, cuentas, carrito, tokens, reservaciones, respuestas, ecommerce, check-ins, permisos, adjuntos y campos extra). Si algo falla, todo se revierte. Ambos clientes deben ser tipo CLIENT, estar ACTIVOS y ser diferentes. Con un solo origen puede usar Intercambiar para invertir los papeles.
